# Segurança

Se você encontrou uma vulnerabilidade em algum projeto da 4koffee, não abra uma issue pública.

Escreva para **4koffee.dev@gmail.com** com:

- o repositório ou sistema afetado;
- os passos para reproduzir;
- o impacto que você identificou.

Respondemos assim que possível e avisamos quando a correção estiver publicada.
